# 🚀 Portafolio Web Profesional - Trabajo Final

Este repositorio contiene el código fuente de mi **Portafolio Web Personal**, desarrollado como el **Trabajo Final del Módulo de Programación Web**. La solución ha sido construida utilizando **React** y **Vite**, gestionando el ciclo de vida del desarrollo a través de **Trello** y utilizando herramientas de **Inteligencia Artificial** como soporte estratégico para optimizar la codificación y el diseño.

El portafolio está diseñado para proyectar mi perfil profesional, destacando mi rol en la fundación de un centro de innovación en Pereira, la dirección de equipos multifuncionales en IA, nube y ciberseguridad, así como la coordinación de paneles técnicos internacionales y redes de mentoría.

---

## 📊 Gestión del Proyecto con Trello

Para garantizar una metodología ágil y ordenada, el desarrollo se estructuró en un tablero de **Trello** bajo el marco de trabajo Kanban, dividido en las siguientes etapas:

* **Backlog / Ideas:** Requerimientos iniciales y secciones del portafolio (Sobre mí, Experiencia, Proyectos, Habilidades, Contacto).
* **Por Hacer (To Do):** Tareas priorizadas para el sprint actual (ej. Configurar enrutamiento, diseñar componentes atómicos).
* **En Proceso (In Progress):** Características en desarrollo activo.
* **Pruebas / QA:** Validación de responsive design, enlaces rotos y optimización de carga con Vite.
* **Terminado (Done):** Características completamente funcionales y listas para despliegue.

## 💻 Instrucciones para la Ejecución Local

Sigue estos pasos para clonar el repositorio y ejecutar la aplicación en tu entorno local:

### Prerrequisitos
Asegúrate de tener instalado [Node.js](https://nodejs.org/).

### 1. Clonar el repositorio
Abre tu terminal y ejecuta el siguiente comando:
`git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git`

### 2. Navegar al directorio del proyecto
`cd mi-portafolio`

### 3. Instalar las dependencias
Instala todos los paquetes y librerías necesarias:
`npm install`

### 4. Ejecutar el servidor de desarrollo
Inicia el entorno de desarrollo local provisto por Vite:
`npm run dev`

### 5. Abrir la aplicación
Una vez ejecutado el comando anterior, la terminal te proporcionará una URL local (usualmente `http://localhost:5173`). Ábrela en tu navegador para interactuar con el portafolio.
